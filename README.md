# 마법 도시 (Magic City) — NeoForge 1.21.1

흰색(석영·방해석)을 메인으로, 민트색(밀랍칠한 산화 구리·하늘색 유리)을 포인트로 쓰는
**반지름 300칸 원형 마법 성채 도시**를 명령어 하나로 자동 생성하는 모드입니다.

## 받는 방법

1. 이 저장소의 **Actions** 탭 → 가장 최근 성공한 빌드(초록 체크)를 누릅니다.
2. 아래쪽 **Artifacts**에서 `magic-city-mod-jar`를 받아 압축을 풉니다.
3. `magiccity-1.0.0.jar`를 NeoForge 1.21.1이 설치된 마인크래프트의 `mods` 폴더에 넣습니다.

코드를 고쳐서 올리면 GitHub가 자동으로 다시 빌드합니다.

## 사용법

1. 크리에이티브 월드(치트 허용)에서 도시 중심이 될 땅 위에 섭니다. **발밑 블록 높이가 가장 바깥 단의 지면**이 됩니다.
2. `/magiccity build` 를 입력합니다. (기본 반지름 600, `/magiccity build 500` 처럼 450~700 지정 가능)
3. 채팅으로 진행률이 표시됩니다. 반지름 600은 PC 성능에 따라 20~40분 정도 걸립니다.
   - `/magiccity status` 진행률 확인
   - `/magiccity cancel` 중단

> 중앙 대성이 매우 높아서 **Y=138 이하**(일반 지면 높이)에서 실행해야 합니다.
> 건설 중에는 도시 근처에 머물러 주세요. 서버를 끄면 건설이 중단되며, 다시 실행하면 처음부터 덮어씁니다.
> 꼭 **백업한 월드나 테스트 월드**에서 실행하세요. 범위 안의 지형은 모두 정리됩니다.

## 도시 구성 (반지름 600, 중심으로 갈수록 높아지는 4단 계단식 도시)

| 반지름 | 단 높이 | 구역 |
|---|---|---|
| 0 ~ 140 | +32 | **성역 고원**: 중앙 대성, 성 광장, 운하, 산책로 |
| 140 ~ 220 | +20 | **학원 구역**: 마법탑, 학원 강당, 분수 정원 |
| 220 ~ 330 | +10 | **상업 구역**: 주민 집, 시장, 분수 광장 |
| 330 ~ 554 | 0 | **외곽 주거 구역** |
| 562 ~ 570 | 0 | 외성벽 (높이 26) + 성문 8개 + 탑 |
| 570 ~ 600 | 0 | 농지, 해자 |

- 단과 단 사이는 흰 석영 옹벽과 유리 난간, 대로(폭 11) 위의 계단 경사로로 이어집니다.
- **중앙 대성**: 높이 96 원형 대성전(민트 돔, 장미창, 버팀벽, 외부 발코니) + 십자 회랑 4개 + 첨탑 4개 + 성벽과 탑 24개.
  안에는 돔까지 뚫린 성소와 신호기 빛줄기, 떠 있는 빛의 고리, 5층 원형 서고 회랑, 나선 대계단, 신도석이 놓인 회랑이 있습니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `city/Palette.java` | **색상 팔레트** — 색을 바꾸려면 이 파일만 수정 |
| `city/CityLayout.java` | 도시 설계도: 구역 반지름, 대로, 성벽·운하·해자·농지, 건물 구획 배치 |
| `city/Shapes.java` | 원형 탑, 지붕, 나무, 분수, 수정, 가로등 |
| `city/feature/*.java` | 건물 종류별 코드 (성채, 성문, 마법탑, 학원, 집, 시장, 정원, 분수) |
| `build/CityBuildJob.java` | 청크 단위로 나눠 짓는 작업 (틱당 25ms) |
| `command/MagicCityCommand.java` | `/magiccity` 명령어 |
