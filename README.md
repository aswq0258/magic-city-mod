# 마법 도시 (Magic City) — NeoForge 1.21.1

흰색(석영·방해석)을 메인으로, 민트색을 포인트로 쓰는 **약 395 x 395 판타지 성채 도시**와
흰색 + 금색의 **다층 왕성**을 명령어 하나로 자동 생성하는 모드입니다.

## 받는 방법

1. 이 저장소의 **Actions** 탭 → 가장 최근 성공한 빌드(초록 체크)를 누릅니다.
2. 아래쪽 **Artifacts**에서 `magic-city-mod-jar`를 받아 압축을 풉니다.
3. `magiccity-1.0.0.jar`를 NeoForge 1.21.1이 설치된 마인크래프트의 `mods` 폴더에 넣습니다.

코드를 고쳐서 올리면 GitHub가 자동으로 다시 빌드합니다.

## 사용법

1. 크리에이티브 월드(치트 허용)에서 도시 중심이 될 땅 위에 섭니다. **발밑 블록 높이가 도시 지면**이 됩니다.
2. `/magiccity build` 를 입력합니다. 도시 범위의 지형을 재서 지면 높이를 **자동으로** 정합니다.
   (발밑 높이를 그대로 쓰려면 `/magiccity build here`)
3. 채팅으로 진행률이 표시됩니다. PC 성능에 따라 **15~30분** 정도 걸립니다.
   - `/magiccity status` 진행률 확인 / `/magiccity cancel` 중단

> 왕성 첨탑이 지면 위 약 145칸까지 올라가므로 지면이 **Y=165 이하**(높이 제한 320 기준)여야 합니다. 성벽 바깥은 원래 지형까지 완만한 잔디 경사로로 이어집니다. 건설이 끝날 때까지 게임을 켜 두세요(끄면 중단, 다시 실행하면 처음부터 덮어씀).
> 꼭 **백업한 월드나 테스트 월드**에서 실행하세요. 도시 약 395 x 395 범위(+ 북문 밖 공동묘지, 둘레 경사로)의 지형이 정리됩니다.

## 왕국 대륙 (커스텀 차원 `magiccity:kingdom`)

마스터플랜 도면 좌표를 왕성 중심 (260, 260) 기준 **2배**로 넓혀 배치합니다 (실제 좌표 = 260 + (도면 - 260) x 2).
지역 사이의 길만 길어지고 각 지역의 크기는 그대로입니다. 길 10개 합계 약 26,000블록 (평균 약 2,600블록).

- `/magiccity kingdom` — 왕국 대륙의 왕성도시 터(260, 260)로 이동 → 거기서 `/magiccity build`
- `/magiccity site oldcapital` — 몰락한 옛 왕도 (월드 -3960, 3260) + 연합군 봉쇄 요새 건설
- `/magiccity goto oldcapital` — 봉쇄 요새로 이동
- `/magiccity boss reset` — 심연의 문지기 재도전 (마계문 닫힘)
- `/magiccity site roads` — 길 10개에 쉼터·몬스터 둥지·필드보스 결투장 건설
- `/magiccity roads` — 길(지역) 목록과 필드보스 위치
- `/magiccity map` — 가 보지 않은 곳까지 그려진 지역 지도 (내 위치 중심 2048 x 2048, 쉼터·둥지·필드보스 표시). `/magiccity map <x> <z>` 로 다른 곳
- `/magiccity map world` — 대륙 전체가 한 장에 그려진 전도

### 길 = 지역
길은 지형이 생성될 때 바로 깔립니다 (왕도/교역로 = 폭 7 돌길 + 가로등, 숲길/산악길 = 폭 5 흙길, 봉쇄된 옛길 = 부서진 돌길, 물 위는 다리).
길(또는 길가 40칸) 에 있으면 그 길의 몬스터 무리가 출몰하고, 길에 들어서면 지역 이름이 표시됩니다. 쉼터 근처는 안전합니다.

| 길 | 지역 | 출몰 | 필드보스 |
|---|---|---|---|
| 북부 왕도 | 설산 원정길 | 스트레이·스켈레톤 | 설원의 백곰왕 |
| 서부 숲길 | 거미 숲길 | 거미·동굴 거미 | 숲의 여왕거미 |
| 엘프 산악길 | 광산 무역로 | 좀비·스켈레톤 | 산악 파괴수 (파괴수) |
| 엘프-북부 고갯길 | 비룡 고갯길 | 팬텀·스켈레톤·거미 | 고갯길의 비룡 (팬텀) |
| 동부 교역로 | 상단 교역로 | 약탈자·변명자 | 약탈단 흑마법사 (소환사) |
| 남부 왕도 | 역병 왕도 | 좀비·좀비 주민·허스크 | 역병 거인 |
| 강변길 | 물귀신 강변길 | 드라운드 | 강의 군주 (삼지창) |
| 남동 교역 연결로 | 늪 교역로 | 마녀·슬라임·보그드 | 늪의 마녀 |
| 남서 국경로 | 저주받은 국경로 | 스켈레톤·좀비 | 저주받은 궁기사 |
| 마왕성 폐왕도 | 마계 오염 옛길 | 마그마 큐브·블레이즈·위더 해골 | 균열의 감시자 (블레이즈) |

필드보스는 결투장 가운데로 다가가면 나타나고, 쓰러뜨리면 15분 뒤 다시 나타납니다.

> 지형 배치가 바뀌었으므로 예전 버전에서 이미 생성된 왕국 대륙 청크는 그대로 남습니다. **새 월드**에서 시험하세요.

## 도시 구성 (520 도면에서 바깥 둘레 띠를 걷어낸 X/Z 63~457, 도면의 북쪽(Z 증가) = 게임의 북쪽(-Z))

주거 건물(집·귀족 저택)을 빼면 **같은 건물은 한 번씩만** 짓습니다.

| 구역 | 건물 |
|---|---|
| 북 · 군사 | 기사단 병영, 훈련장, 무기고, 마구간, 보급 창고, 병사 가족 주거지 |
| 북동 · 마법 | 마법 학원, 마법사의 탑, 마법 상점, 마법사 주거지 2곳, 정원 |
| 서 · 장인 | 대장간, 공방, 장인 주거지 / **슬럼가** (판잣집·진흙 골목·빨랫줄·하수도 맨홀) |
| 동 · 귀족·종교 | 대성당, **별빛의 신전**(원형 열주·떠 있는 거대 수정·연꽃 연못), 귀족 저택 3채 |
| 남 · 시장·상업 | 중앙 시장 광장, 시장 골목, 여관, 분수 광장, **모험가 길드**(본관 + 망루·의뢰 게시판·훈련장·모닥불 쉼터), 주거지 4곳 |
| 하늘 | 떠다니는 섬 5개 (자작나무·꽃·아래에 매달린 자수정) |
| 땅속 | **왕성 하수도 던전** (아래 참고) |

- **외성벽(사람이 다니는 성벽)**: 높이 24, 닳은 보행로(방해석·섬록암·금 간 석재가 섞임), 안쪽 난간 랜턴, 바깥 민트 깃발,
  면마다 성벽으로 올라가는 계단 2개와 꼭대기 초소(통·건초·모닥불·숫돌), 성벽 밑 닳은 흙길, 성문 밖으로 이어지는 흙길
- **가로등**: 흰 석영 가로등과 판타지 수정 가로등(떠 있는 엔드 막대)을 섞음

### 왕성 하수도 던전 (지면 16칸 아래)

- 입구: 슬럼가 맨홀(사다리) / 왕성 1단 테라스 서쪽의 비밀 사다리
- 폭 7 하수로(가운데 물길·보행로·영혼 랜턴·거미줄·뼈)가 왕성 아래를 한 바퀴 돌고 세 갈래로 이어짐
  - **초대 왕의 납골당** (주탑 바로 아래): 석관, 금 제단, 보물 상자(고대 도시·던전 전리품), 스켈레톤 스포너 2개
  - **지하 저수조**: 기둥 사이 깊은 물, 좀비 스포너, 상자
  - **지하 감옥**: 철창 감방, 사슬, 거미·좀비 스포너, 간수 상자

### 다층 왕성 (X/Z 195~325, 프랑스 고딕·르네상스 샤토 양식: 흰 벽 + 금 장식 + 슬레이트 지붕)

대칭이 아니지만 균형 잡힌 구성: 주탑의 2·3단은 남서쪽으로 치우치고, 북동쪽에 가장 높은 망루, 남서쪽에 낮고 굵은 탑을 두어 무게를 맞춤.
성벽 모서리 탑과 성문 탑의 굵기·높이도 제각각이고, 테라스 위 건물마다 부속 탑이 다름
(예배당 종탑, 마법서고의 마법사 탑 + 떠 있는 수정·금빛 고리, 금고 탑, 근위대 사각 망루). 첨탑 둘레에는 금빛 고리가 떠 있음.


| 높이 | 구성 |
|---|---|
| 0 | 해자, 해자를 건너 +8 까지 올라가는 경사 둑길 4개 |
| +8 (1단 테라스) | 왕성 성벽(높이 28, 모서리 큰 탑·성문 탑), 왕성 앞뜰(화단·분수·조각상), 왕좌의 전당(높이 22, 3단 옥좌·붉은 천개·열주), 왕실 의회실, 왕실 예배당(금빛 창·금 돔), 금고·서고, 왕궁 마법서고, 근위대 병영, 왕립 무기고 |
| +18 (2단 테라스) | 옹벽·난간, 남쪽 대계단과 동서 계단, 왕좌의 전당 +18 회랑과 다리로 연결 |
| +18 ~ +42 | 중앙 주탑 1단: 대현관홀 / 왕실 서재 / 연회장 |
| +42 ~ +60 | 2단: 국왕·왕비 침실 / 집무실 |
| +60 ~ +76 | 3단: 기도실 / 보물실 |
| 지붕 | 가파른 슬레이트 모임지붕(맨사드)·돌 지붕창(뤼카른)·장식 굴뚝, 벽에 매달린 작은 탑(에쇼게트), 세로살 창, 원뿔 첨탑, 전당·예배당의 고딕 플레슈 |
| +76 ~ 약 +143 | 첨탑: 관측실, 높이 30 바늘 원뿔 첨탑 + 둘레 작은 첨탑 (가운데 나선 대계단으로 관측실까지) |
