# 마법 도시 (Magic City) — NeoForge 1.21.1

흰색(석영·방해석)을 메인으로, 민트색(밀랍칠한 산화 구리·하늘색 유리)을 포인트로 쓰는
**반지름 300칸 원형 마법 성채 도시**를 명령어 하나로 자동 생성하는 모드입니다.

## 받는 방법

1. 이 저장소의 **Actions** 탭 → 가장 최근 성공한 빌드(초록 체크)를 누릅니다.
2. 아래쪽 **Artifacts**에서 `magic-city-mod-jar`를 받아 압축을 풉니다.
3. `magiccity-1.0.0.jar`를 NeoForge 1.21.1이 설치된 마인크래프트의 `mods` 폴더에 넣습니다.

코드를 고쳐서 올리면 GitHub가 자동으로 다시 빌드합니다.

## 사용법

1. 크리에이티브 월드(치트 허용)에서 도시 중심이 될 땅 위에 섭니다. **발밑 블록 높이가 도시 지면**이 됩니다.
2. `/magiccity build` 를 입력합니다. (반지름 지정: `/magiccity build 250`, 200~400)
3. 채팅으로 진행률이 표시됩니다. 보통 5~10분 걸립니다.
   - `/magiccity status` 진행률 확인
   - `/magiccity cancel` 중단

> 건설 중에는 도시 근처에 머물러 주세요. 서버를 끄면 건설이 중단되며, 다시 실행하면 처음부터 덮어씁니다.
> 꼭 **백업한 월드나 테스트 월드**에서 먼저 실행해 보세요. 지정한 범위 안의 지형은 평평하게 정리됩니다.

## 도시 구성 (반지름 300 기준)

| 반지름 | 구역 |
|---|---|
| 0 ~ 56 | 중앙 광장 + **성채**: 높이 64 대성탑, 민트 돔과 첨탑, 공중 고리, 떠 있는 수정 4개, 내성벽과 탑 8개 |
| 58 ~ 63 | 운하 (대로마다 다리) |
| 65 ~ 144 | **마법 학원 구역**: 공중 고리가 도는 마법탑, 모서리 첨탑이 있는 학원 건물, 분수 정원 |
| 144 ~ 151 | 1번 순환도로 |
| 151 ~ 252 | **주거·시장 구역**: 주민 집(침대·직업 블록), 시장 노점, 정원, 분수 광장 |
| 254 ~ 261 | 2번 순환도로 |
| 262 ~ 270 | **외성벽** (높이 22) + 성문 8개(양옆 탑) + 성벽 탑 8개 |
| 270 ~ 280 | 농지 (밀·당근·감자, 물길) |
| 280 ~ 294 | 해자 (대로마다 다리) |

- 중심에서 바깥으로 폭 9칸의 **대로 8개**가 뻗어 있습니다 (흰 석영 + 민트 경계선).
- 10칸 간격 가로등(바다 랜턴)으로 도시 전체를 밝혀 몬스터가 생기지 않게 했습니다.
- 주민은 최대 약 120명까지 배치됩니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `city/Palette.java` | **색상 팔레트** — 색을 바꾸려면 이 파일만 수정 |
| `city/CityLayout.java` | 도시 설계도: 구역 반지름, 대로, 성벽·운하·해자·농지, 건물 구획 배치 |
| `city/Shapes.java` | 원형 탑, 지붕, 나무, 분수, 수정, 가로등 |
| `city/feature/*.java` | 건물 종류별 코드 (성채, 성문, 마법탑, 학원, 집, 시장, 정원, 분수) |
| `build/CityBuildJob.java` | 청크 단위로 나눠 짓는 작업 (틱당 25ms) |
| `command/MagicCityCommand.java` | `/magiccity` 명령어 |
