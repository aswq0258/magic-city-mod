# 마법 도시 (Magic City) — NeoForge 1.21.1

흰색(석영·방해석)을 메인으로, 민트색을 포인트로 쓰는 **520 x 520 판타지 성채 도시**와
흰색 + 금색의 **다층 왕성**을 명령어 하나로 자동 생성하는 모드입니다.

## 받는 방법

1. 이 저장소의 **Actions** 탭 → 가장 최근 성공한 빌드(초록 체크)를 누릅니다.
2. 아래쪽 **Artifacts**에서 `magic-city-mod-jar`를 받아 압축을 풉니다.
3. `magiccity-1.0.0.jar`를 NeoForge 1.21.1이 설치된 마인크래프트의 `mods` 폴더에 넣습니다.

코드를 고쳐서 올리면 GitHub가 자동으로 다시 빌드합니다.

## 사용법

1. 크리에이티브 월드(치트 허용)에서 도시 중심이 될 땅 위에 섭니다. **발밑 블록 높이가 도시 지면**이 됩니다.
2. `/magiccity build` 를 입력합니다.
3. 채팅으로 진행률이 표시됩니다. PC 성능에 따라 **20~40분** 정도 걸립니다.
   - `/magiccity status` 진행률 확인 / `/magiccity cancel` 중단

> 왕성 첨탑이 지면 위 약 145칸까지 올라가므로 **Y=165 이하**에서 실행하세요. 건설이 끝날 때까지 게임을 켜 두세요(끄면 중단, 다시 실행하면 처음부터 덮어씀).
> 꼭 **백업한 월드나 테스트 월드**에서 실행하세요. 도시 520 x 520 범위(+ 북문 밖 공동묘지)의 지형이 정리됩니다.

## 도시 구성 (도면 좌표 X/Z 0~520, 도면의 북쪽(Z 증가) = 게임의 북쪽(-Z))

```
            [ 북문 ] ── 북문 밖: 공동묘지
  N04 병영  N03 무기고 │ N01 기사단 본부 │ N07 학원 · N08~N10 마법탑
  N05 마구간 N06 보급창고│ N02 훈련장     │ N11 마법 상점 · N12 정원
  W01~W04 대장간·공방 ─ [ 해자 + 다층 왕성 ] ─ E01 대성당 · E03/E04 귀족 저택
  S04 시장 · S02/S03/S05 상점·여관 │ S01 중앙 시장 광장 │ S06 모험가 길드·여관, S07 여관, S08~S11 상점
  둘레 P01~P16: 주거지 · 공원·분수 광장 · 물류 창고·마구간 · 수비대 주둔지 · 남쪽 시장
            [ 남문 ]
```

- **외성벽**: 높이 24, 민트 띠와 총안, 모서리 큰 탑 4개 · 중간 탑 8개 · 성문 탑 8개, 동서남북 아치 성문
- **도로**: 성벽 안 순환로, 외곽 순환로, 왕성 순환로, 성문 대로 4개, 보조 도로 8개 (가로등)
- **구획**: 구역마다 바닥 무늬와 소품(군사: 건초·과녁 / 장인: 통·장작·모루 / 물류: 건초 더미·상자 / 마법: 꽃·자수정), 자작나무, 가로등

### 다층 왕성 (X/Z 195~325, 흰색 + 금)

| 높이 | 구성 |
|---|---|
| 0 | 해자, 해자를 건너 +8 까지 올라가는 경사 둑길 4개 |
| +8 (1단 테라스) | 왕성 성벽(높이 28, 모서리 큰 탑·성문 탑), 왕성 앞뜰(화단·분수·조각상), 왕좌의 전당(높이 22, 3단 옥좌·붉은 천개·열주), 왕실 의회실, 왕실 예배당(금빛 창·금 돔), 금고·서고, 왕궁 마법서고, 근위대 병영, 왕립 무기고 |
| +18 (2단 테라스) | 옹벽·난간, 남쪽 대계단과 동서 계단, 왕좌의 전당 +18 회랑과 다리로 연결 |
| +18 ~ +42 | 중앙 주탑 1단: 대현관홀 / 왕실 서재 / 연회장 |
| +42 ~ +60 | 2단: 국왕·왕비 침실 / 집무실 |
| +60 ~ +76 | 3단: 기도실 / 보물실 |
| +76 ~ 약 +143 | 첨탑: 관측실, 높이 30 바늘 원뿔 첨탑 + 둘레 작은 첨탑 (가운데 나선 대계단으로 관측실까지) |

## 코드 구조

| 파일 | 역할 |
|---|---|
| `city/Palette.java` | **도시 색상 팔레트** (흰색 + 민트) |
| `city/Royal.java` | **왕성 팔레트와 가구** (흰색 + 금, 붉은 카펫, 금 샹들리에) |
| `city/CityLayout.java` | 도시 설계도: 도면 좌표, 구획·도로·성벽·해자·묘지, 건물 배치 |
| `city/feature/RoyalCastle.java`, `RoyalHall.java`, `Keep.java` | 다층 왕성: 성벽·둑길·테라스 / 테라스 위 건물 / 중앙 주탑 |
| `city/Shapes.java` | 원형 탑, 지붕, 나무, 분수, 수정, 가로등 |
| `city/feature/*.java` | 건물 종류별 코드 (성채, 성문, 마법탑, 학원, 집, 시장, 정원, 분수) |
| `build/CityBuildJob.java` | 청크 단위로 나눠 짓는 작업 (틱당 25ms) |
| `command/MagicCityCommand.java` | `/magiccity` 명령어 |
