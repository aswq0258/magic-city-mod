# 마법 도시 (Magic City) — NeoForge 1.21.1

흰색(석영·방해석)을 메인으로, 민트색을 포인트로 쓰는 **약 395 x 395 판타지 성채 도시**와
흰색 + 금색의 **다층 왕성**을 명령어 하나로 자동 생성하는 모드입니다.

## 받는 방법

1. 이 저장소의 **Actions** 탭 → 가장 최근 성공한 빌드(초록 체크)를 누릅니다.
2. 아래쪽 **Artifacts**에서 `magic-city-mod-jar`를 받아 압축을 풉니다.
3. `magiccity-1.0.0.jar`를 NeoForge 1.21.1이 설치된 마인크래프트의 `mods` 폴더에 넣습니다.

코드를 고쳐서 올리면 GitHub가 자동으로 다시 빌드합니다.

## 사용법

1. 크리에이티브 월드(치트 허용)에서 도시 중심이 될 땅 위에 섭니다. **발밑 블록 높이가 도시 지면**이 됩니다.
2. `/magiccity build` 를 입력합니다. 도시 범위의 지형을 재서 지면 높이를 **자동으로** 정합니다.
   (발밑 높이를 그대로 쓰려면 `/magiccity build here`)
3. 채팅으로 진행률이 표시됩니다. PC 성능에 따라 **15~30분** 정도 걸립니다.
   - `/magiccity status` 진행률 확인 / `/magiccity cancel` 중단

> 왕성 첨탑이 지면 위 약 145칸까지 올라가므로 지면이 **Y=165 이하**(높이 제한 320 기준)여야 합니다. 성벽 바깥은 원래 지형까지 완만한 잔디 경사로로 이어집니다. 건설이 끝날 때까지 게임을 켜 두세요(끄면 중단, 다시 실행하면 처음부터 덮어씀).
> 꼭 **백업한 월드나 테스트 월드**에서 실행하세요. 도시 약 395 x 395 범위(+ 북문 밖 공동묘지, 둘레 경사로)의 지형이 정리됩니다.

## 왕국 대륙 (커스텀 차원 `magiccity:kingdom`)

마스터플랜 도면 좌표를 왕성 중심 (260, 260) 기준 **2배**로 넓혀 배치합니다 (실제 좌표 = 260 + (도면 - 260) x 2).
지역 사이의 길만 길어지고 각 지역의 크기는 그대로입니다. 길 10개 합계 약 26,000블록 (평균 약 2,600블록).

- `/magiccity kingdom` — 왕국 대륙의 왕성도시 터(260, 260)로 이동 → 거기서 `/magiccity build` (구시가지 + 신시가지)
- `/magiccity build expansion` — 이미 지은 도시 바깥에 신시가지만 덧짓기
- `/magiccity site oldcapital` — 몰락한 옛 왕도 (월드 -3960, 3260) + 연합군 봉쇄 요새 건설
- `/magiccity goto oldcapital` — 봉쇄 요새로 이동
- `/magiccity boss reset` — 심연의 문지기 재도전 (마계문 닫힘)
- `/magiccity site roads` — 길 10개에 쉼터·몬스터 둥지·필드보스 결투장 건설
- `/magiccity roads` — 길(지역) 목록과 필드보스 위치
- `/magiccity map` — 가 보지 않은 곳까지 그려진 지역 지도 (내 위치 중심 2048 x 2048, 쉼터·둥지·필드보스 표시). `/magiccity map <x> <z>` 로 다른 곳
- `/magiccity map world` — 대륙 전체가 한 장에 그려진 전도
- `/magiccity site worldtree` — 세계수 성역 건설 (세계수·나선 계단 전망대·정령호·엘프 나무집 10채·장로의 전당), `/magiccity goto worldtree` 로 이동. 성역 안(반경 230)은 수관 밑이 어두워도 몬스터가 저절로 생기지 않음
- 세계수를 둘러싼 엘프 대수림 심부는 "태고의 숲": 지름 5~7 의 고목(뿌리 버팀목·가지·진달래 잎·버섯불·발광 열매 덩굴·포자 꽃), 이끼·포드졸 바닥과 고사리, 쓰러진 이끼 통나무, 선돌, 요정의 버섯 고리. 새로 생성되는 땅에는 자동, 이미 생성된 땅은 `/magiccity fix deepwood`
- `/magiccity fix elfwood` — 세계수 주변 반지름 360 을 "보랏빛 숲"으로: 엘프의 성역 바이옴(보라색 안개·풀·물·잎, 떠도는 보랏빛 입자, 비 없음), 지면 위 약 66칸의 잎 천장(이끼층이 햇빛을 막음, 가장자리는 땅까지 내려온 장막, 길만 아치로 열림), 천장에 매달린 보랏빛 구슬·청록 수정·발광 열매 덩굴, 빛나는 버섯·보랏빛 작은 나무·자수정·분홍 꽃잎. 새로 생성되는 땅은 자동. 기존 월드는 이 명령 뒤 `site worldtree`, `site rootcave` 를 다시 돌려 세계수도 보랏빛으로. 숲 전체가 몬스터 자연 스폰 없음
- `/magiccity fix seams` — 건축물을 철거(remove)한 네모난 영역의 가장자리에서 나무가 칼로 자른 듯 반쪽만 남은 곳을 고침. 태고의 숲 고목은 다시 그려 잘린 반쪽을 되살리고, 그 밖의 숲은 가장자리에 걸친 나무를 치우고 새로 심음 (건축물 자리는 그대로)
- `/magiccity site rootcave` — 세계수 뿌리 던전 ("세계수 기생충"의 둥지). `site worldtree` 다음에 실행. 밑동 남쪽 틈 → 줄기 속 나선 계단 → 뿌리 회랑(지하 26칸: 수액 샘·감염된 둥지·고치 방·엘프 탐사대 야영지·하강 동굴) → 기생충의 둥지(지하 64칸, 지름 약 70 돔, 천장에서 내려온 원뿌리, 가운데 수액 웅덩이가 보스 자리) → 보상 방과 돌아가는 나선. `/magiccity goto rootcave` 입구, `goto parasite` 보스 방, `remove rootcave` 철거
- `/magiccity site port` — 동해안 항구도시 벨마르 (성벽·성문탑·분수 광장·항만청·해신 신전·세관·여관·창고·어시장·조선소·잔교 4개·정박 범선·방파제 등대) + 앞바다 등대 섬 (거대 등대·등대지기 오두막·해상신전·잠긴 성소의 보스 "심해의 수호자"), `/magiccity goto port`, `/magiccity goto lighthouse` 로 이동
- `/magiccity site dragon` — 고룡 봉우리 드래곤 레어: 강이 시작되는 협곡 끝의 용의 동굴(용의 길 끝) → 샘의 동굴 → 나선 목구멍 → 상층 미궁(Y 30, 11x11 미로, 방 6종) → 하층 불의 미궁(Y 6, 용암 도랑·외줄 다리) → 보물 동굴(Y -40)의 보스 "고룡 이그나르". `/magiccity goto dragon` 으로 이동
- `/magiccity site sky` — 부유섬 유적 "천공의 유적": 지류의 샘 위 하늘에 뜬 섬 7개(무너진 신전과 폭포, 수정 첨탑, 무너진 서고, 공중 정원, 별 관측소, 폭풍의 결투장, 보물고), 사슬 다리·디딤돌, 땅의 사슬 오벨리스크와 천공의 탑(나선 계단), 학자 야영지(느린 낙하 물약), 보스 "폭풍의 수호자". `/magiccity goto sky` 로 이동
- `/magiccity site cursed` — 저주받은 숲(잎이 반쯤 떨어진 시든 숲·죽은 고목·매달린 철창·교수대·검은 연못가 마녀의 오두막·저주받은 제단과 보스 "저주의 마녀왕") + 심연 균열(길이 260·Y -30 까지 갈라진 V 자 협곡, 용암 강, 사슬 다리, 나선 계단 굴, 스컬크 폐허와 깨어날 수 있는 비명체). `/magiccity goto cursed`, `/magiccity goto rift`
- `/magiccity site border` — 남부 국경도시 "로젠하르트": 능보 6개의 별 모양 성벽(망루·대포)과 물 해자·도개교 문루, 열병 광장(기사상), 성채, 병영 3동, 훈련장, 마구간(말), 무기고, 대장간, 종탑 예배당, 곡물 창고, 여관 "국경의 등불", 집 약 60채. `/magiccity goto border`
- `/magiccity site ruins` — 고대 왕국 유적 "아르케이아": 지름 140·깊이 12 의 계단식 발굴 구덩이(경사로·사다리), 열주 대로·무너진 대신전·쓰러진 거상·묻힌 집터, 붓으로 털 수 있는 수상한 모래·자갈, 오벨리스크·발굴 야영지(붓 상자), 대신전 아래 왕릉(석관 회랑·보물실·왕의 묘실과 보스 "고대왕 아르케온"). 발굴 야영지에서 "유적 탐사로"로 이어짐. `/magiccity goto ruins`
- `/magiccity site elfgate` — 엘프 산맥 관문 "은빛 협문": 엘프-북부 고갯길의 협곡을 가로막은 흰 성벽과 아치 문루(쇠살문·은빛 문장), 구리 첨탑 원탑 2개, 엘프 안뜰(둥근 막사·원형 마구간·달의 제단·우물), 엘프 파수꾼·숲의 정령·흰 말·북쪽 눈 골렘. `/magiccity goto elfgate`
- `/magiccity site dwarf` — 드워프 광산왕국 건설 (산의 문·드워프 왕 거상·대전당·옥좌실·대장간(장인의 5×5 작업대 단 — `fantasyrpg` 5×5 작업대가 있으면 그 블록, 없으면 바닐라 작업대)·주거 회랑·광산·자수정 정동·잃어버린 광부의 갱도), `/magiccity goto dwarf` 로 이동
- `/magiccity site deepmine` — 드워프 심층 광산, 5장 "꺼지지 않는 용광로" 던전 (`site dwarf` 다음에). 광산 동쪽 갱도의 뜯겨 나간 봉쇄문 → 계단 갱도 20칸 → 심부 광산(지면 −36: 밝은 갱도 집결지·광부 피난처, 계단식 노천 채굴장, 북쪽 붕괴 갱도·서쪽 무너진 채굴조, 갇힌 실종 광부 3명, 좀비·동굴거미·스켈레톤 스포너) → 깨진 고대 봉인문 → 나선 24칸 → 고대 용광로 홀(지면 −60, 지름 약 54 돔, 용암 해자·다리 3개·압력 밸브 장치 3개, 오염된 고대 용광로, 불꽃의 봉인 제단, 마그마 큐브·블레이즈 스포너). **5장 보스 "용광로의 거신"은 이제 이 홀의 섬 남쪽에서 깨어남** (예전 대장간 자리 아님). 서쪽 보상 방 → 사다리 귀환 갱 → 붕괴 갱도 → 집결지로 복귀. `/magiccity goto deepmine` 갱도 문, `goto furnace` 용광로 홀, `remove deepmine` 철거(광산 층 갱도 문 방은 남음)
- `/magiccity site hamlets` — 촌락 배치 마스터플랜의 촌락 16곳 + 전초기지 4곳 건설 (역참촌·농촌·제분촌·수차촌·교역촌·숲 전초마을·엘프 순례촌·약초촌·드워프 운송촌·혹한 마을·빙해 항구·어촌·늪지 수상촌·변경 경비촌, 보급초소·등대초소·발굴 야영지·피난민 은신처), `/magiccity hamlets` 로 가까운 촌락 목록
- 마을을 잇는 지선 7개와 남서 국경 군용로·폐왕도 잔해길 (이미 생성된 대륙은 `/magiccity fix roads` 로 깔림)
- `/magiccity remove <hamlets|hamlet|roads|worldtree|dwarf|oldcapital>` — 왕국 대륙에 지은 건축물을 철거하고 원래 지형으로 되돌림 (`hamlet` = 가장 가까운 촌락 하나). 나무·풀은 되살아나지 않음
- `/magiccity fix roads` — 이미 생성된 왕국 대륙에서 길만 그 자리에서 고침 (도시 근처 길·강 다시 깔기, 길가 5블록 나무 정리, 신시가지 다시 짓기). 대륙을 다시 생성하지 않아도 됨
- `/magiccity remove city` — 왕성도시(구시가지 + 신시가지) 철거. 왕국 대륙은 원래 지형 그대로, 다른 차원은 기본 지형 + 흙·풀로 되돌림
- `/magiccity remove all` — 왕국 대륙의 모든 건축물(촌락·길 거점·세계수·드워프·옛 왕도) + 왕성도시를 차례로 철거
- 왕국 대륙에는 바닐라 구조물(마을·약탈자 전초기지·폐허 포탈 등) 이 생성되지 않습니다.

### 길 = 지역
길은 지형이 생성될 때 바로 깔립니다 (왕도/교역로 = 폭 7 돌길 + 가로등, 숲길/산악길 = 폭 5 흙길, 봉쇄된 옛길 = 부서진 돌길, 물 위는 다리).
길(또는 길가 40칸) 에 있으면 그 길의 몬스터 무리가 출몰하고, 길에 들어서면 지역 이름이 표시됩니다. 쉼터 근처는 안전합니다.

| 길 | 지역 | 출몰 | 필드보스 |
|---|---|---|---|
| 북부 왕도 | 설산 원정길 | 스트레이·스켈레톤 | 설원의 백곰왕 |
| 서부 숲길 | 거미 숲길 | 거미·동굴 거미 | 숲의 여왕거미 |
| 엘프 산악길 | 광산 무역로 | 좀비·스켈레톤 | 산악 파괴수 (파괴수) |
| 엘프-북부 고갯길 | 비룡 고갯길 | 팬텀·스켈레톤·거미 | 고갯길의 비룡 (팬텀) |
| 동부 교역로 | 상단 교역로 | 약탈자·변명자 | 약탈단 흑마법사 (소환사) |
| 남부 왕도 | 역병 왕도 | 좀비·좀비 주민·허스크 | 역병 거인 |
| 강변길 | 물귀신 강변길 | 드라운드 | 강의 군주 (삼지창) |
| 남동 교역 연결로 | 늪 교역로 | 마녀·슬라임·보그드 | 늪의 마녀 |
| 남서 국경로 | 저주받은 국경로 | 스켈레톤·좀비 | 저주받은 궁기사 |
| 마왕성 폐왕도 | 마계 오염 옛길 | 마그마 큐브·블레이즈·위더 해골 | 균열의 감시자 (블레이즈) |

필드보스는 결투장 가운데로 다가가면 나타나고, 쓰러뜨리면 15분 뒤 다시 나타납니다.

> 지형 배치가 바뀌었으므로 예전 버전에서 이미 생성된 왕국 대륙 청크는 그대로 남습니다. **새 월드**에서 시험하세요.

## 신시가지 (원형 구시가지 밖으로 자라난 수도)

`/magiccity build` 는 원형 성곽 도시(구시가지) 와 그 바깥 신시가지·외곽 생활권(약 1240 x 1240) 을 함께 짓습니다.
이미 예전 버전으로 도시를 지은 월드는 `/magiccity build expansion` 으로 성곽 안은 그대로 두고 바깥만 덧지을 수 있습니다.

## 메인 스토리 (초안)
- `/magiccity story` — 12챕터 진행도, 모은 봉인(숲·생명·대지·바다·하늘), 다음 목적지. 챕터 보스를 처음 쓰러뜨리면 64칸 안의 플레이어 모두 완료 처리
- 입장 조건: 1장(서장)을 먼저 끝내야 2~10장 보스가 깨어남(2~10장은 자유 순서). 11장 고룡 이그나르는 1~10장 모두 완료 + 봉인 5개, 12장 심연의 문지기는 11장 완료가 있어야 깨어남
- 진행도: 처음 완료한 챕터 수로 등급이 정해짐 (0~1개 1급, 2~3개 2급, 4~5개 3급, 6~7개 4급, 8~9개 5급, 10개 이상 6급). 레벨 상한 = 등급 × 10, 작업대는 2개 완료 시 4×4, 6개 완료 시 5×5 (레벨·작업대 시스템은 아직 없고 표시와 API만 있음). 같은 챕터를 다시 깨도 진행도는 오르지 않음
- 챕터 보스 등급: 보스가 깨어날 때 그 자리 플레이어 중 가장 높은 진행도로 등급을 정하고 전투 중에는 바꾸지 않음(11·12장은 6급 고정). 보스가 주는 모든 피해는 근접 공격이 그 등급의 보스 기본 공격(1~6급: 8, 11, 14, 15, 17, 18)이 되도록 같은 배율로 조정. 1·2급은 33% 두 번째 부하 소환을 하지 않음. 체력바에 등급 표시
- 설정 `config/magiccity-progression.json`: `enabled`(등급 조정 켜기/끄기), `boss_basic`(등급별 보스 기본 공격), `hp_scale`(등급별 보스 체력 배율, 기본 1.0 = 기존 체력). `/magiccity story config` 로 다시 읽기
- 새 챕터 보스 (외형은 임시로 바닐라 몹을 키운 모습): 1장 하수도의 역병 술사(왕성 하수도 납골당) · 3장 세계수 기생충(뿌리 던전) · 4장 서리 거인 요툰(`site frost` 서리 결투장) · 5장 용광로의 거신(드워프 대장간) · 6장 심해의 수호자(잠긴 성소, 이제 다가가면 깨어나는 관리형) · 8장 약탈 군주 그림발드(국경도시 남쪽 들판, 습격 3단계 뒤) · 10장 심연의 감시자(심연 균열 바닥)
- `/magiccity site sewer` — 왕성 하수도 확장 (build 다음에). 왕궁 아래 순환 하수로 벽의 쇠창살 너머로 도시 끝까지 뻗은 거대한 간선 하수도 4개와 집수 홀이 보이지만 들어갈 수는 없음. 하수로 물길은 8칸마다 솟는 물이 흘러 퍼지고 16칸마다 천장 배수구에서 물이 쏟아짐. 왕궁 비밀 사다리는 이제 지하감옥 남쪽 감방으로 이어지고, 하수로와 지하감옥은 감방 벽 덩굴 뒤 좁은 틈으로만 몰래 이어짐. 슬럼가 맨홀 하수로 서쪽 벽의 덩굴 장막 뒤(또는 맨홀 사다리 중간의 덩굴 뒤)에 암시장 은신처(암시장 상인·정보상·위조 장인·그림자 길드 중개인, 노름판, 장물 창고). 1장 보스는 순환 하수로 남쪽의 초대 왕의 납골당
- 시험용: `/magiccity story give <장>` 처음 완료로 기록(완료 이벤트 발행), `/magiccity story mark <장>` 이벤트 없이 완료 표시, `/magiccity story reset` 초기화, `/magiccity story config` 진행도 설정 다시 읽기

## 다른 모드에서 쓰기 (API)
- 공개 API는 `io.github.aswq0258.magiccity.api` 패키지만 쓴다 (나머지는 내부 구현).
  - `MagicCityApi.completed / grade / levelCap / craftGrid / cleared(ServerPlayer)` — 서버 쪽, 읽기 전용. `API_VERSION` = 1
  - `ChapterFirstClearEvent` — 플레이어가 메인 챕터를 처음 완료하면 `NeoForge.EVENT_BUS`에 한 번 발행 (완료 기록이 반영된 뒤). 재처치에서는 발행하지 않음. 챕터, 완료 수·등급·레벨 상한·작업대 크기의 전·후 값을 담음
- Gradle 의존성 (JitPack, 저장소가 공개라 바로 쓸 수 있음):
```groovy
repositories { maven { url 'https://jitpack.io' } }
dependencies {
    compileOnly  "com.github.aswq0258:magic-city-mod:<커밋 해시>"
    localRuntime "com.github.aswq0258:magic-city-mod:<커밋 해시>"   // 개발용 실행에만
}
```
- 쓰는 쪽 `neoforge.mods.toml`에 `modId="magiccity"`, `type="required"`, `ordering="AFTER"`를 선언한다. magiccity는 NeoForge 21.1.266 이상이 필요하다.
