# 마법 도시 (Magic City) — NeoForge 1.21.1

흰색(석영·방해석)을 메인으로, 민트색(밀랍칠한 산화 구리·하늘색 유리)을 포인트로 쓰는
**반지름 300칸 원형 마법 성채 도시**를 명령어 하나로 자동 생성하는 모드입니다.

## 받는 방법

1. 이 저장소의 **Actions** 탭 → 가장 최근 성공한 빌드(초록 체크)를 누릅니다.
2. 아래쪽 **Artifacts**에서 `magic-city-mod-jar`를 받아 압축을 풉니다.
3. `magiccity-1.0.0.jar`를 NeoForge 1.21.1이 설치된 마인크래프트의 `mods` 폴더에 넣습니다.

코드를 고쳐서 올리면 GitHub가 자동으로 다시 빌드합니다.

## 사용법

1. 크리에이티브 월드(치트 허용)에서 도시 중심이 될 땅 위에 섭니다. **발밑 블록 높이가 도시 지면**이 됩니다.
2. `/magiccity build` 를 입력합니다. (성벽 지름 기본 2000, `/magiccity build 1800` 처럼 1600~2400 지정 가능)
3. 채팅으로 진행률이 표시됩니다. 규모가 매우 커서 PC 성능에 따라 **1~3시간** 걸릴 수 있습니다.
   - `/magiccity status` 진행률 확인 / `/magiccity cancel` 중단

> **Y=200 이하**(일반 지면 높이)에서 실행하세요. 건설이 끝날 때까지 게임을 켜 두세요(끄면 중단, 다시 실행하면 처음부터 덮어씀).
> 꼭 **백업한 월드나 테스트 월드**에서 실행하세요. 범위(지름 약 2200) 안의 지형이 모두 정리됩니다.

## 도시 구성 (성곽 대도시, 지름 2000)

```
                       북문
        모험가 길드·여관 │ 병영·훈련장 │ 군수창고 │ 귀족 저택
  서문  공방 ───── [ 해자 + 중앙 왕성 (지름 500) ] ───── 귀족 저택  동문
        대장간          │                         │ 대성당
        창고·마구간     │ 시장 광장 │ 상점·여관   │ 주거지
                       남문            (성벽 밖 북동쪽: 공동묘지)
```

- **성곽**: 둥근 사각형 성벽(높이 30)과 해자, 동서남북 성문(문루 + 탑), 성벽 탑, 폭 15 대로와 80칸 간격 골목
- **구역별 건물**: 병영(식당·침상·깃발), 훈련장(과녁·허수아비), 군수창고, 창고, 마구간(말), 대장간(화로·모루·굴뚝),
  공방, 상점(매장·살림집), 여관(선술집·객실), 모험가 길드(접수·자료실·숙소), 귀족 저택(붉은 카펫·연회 식당·서재·침실·앞뜰 분수),
  대성당(쌍탑·장미창·돔·신도석·제단), 시장 광장(큰 분수·노점), 주민 집
- **성벽 밖**: 농지, 북동쪽 공동묘지(묘비·촛불·영혼 랜턴·영묘)
- **중앙 왕성 (흰색 + 금, 르네상스 양식)**
  - 성벽(금 띠)과 흰 돔·금 첨탑의 원형 탑 20개, 정문(남문)
  - ㄷ자 궁전: 본관 + 서쪽 날개(대연회장) + 동쪽 날개(무도회장), 3단 기단, 거대 기둥과 금 기둥머리, 지붕 난간의 금 조각상
  - 원형 알현실: 지름 60 돔(금 갈비뼈 + 채광탑), 금 기둥머리 열주, 2층 원형 회랑, 3단 위 금 옥좌와 붉은 천개, 붉은 카펫, 금 샹들리에
  - 남쪽 열주 현관(거대 기둥 + 금 메달리온 박공)
  - 방: 붉은 캐노피 침대 침실, 서재, 식당, 살롱, 집무실, 보물고, 조각 전시실, 왕복 계단실 / 복도는 붉은 카펫 + 금 테두리
  - 정원: 금 별 무늬 명예의 안뜰, 쌍둥이 반사 연못, 화단 정원(산울타리·붉은/흰 꽃·분수), 숲 정원과 정자, 북쪽 정원

## 코드 구조

| 파일 | 역할 |
|---|---|
| `city/Palette.java` | **도시 색상 팔레트** (흰색 + 민트) |
| `city/Royal.java` | **왕성 팔레트와 가구** (흰색 + 금, 붉은 카펫, 금 샹들리에) |
| `city/CityLayout.java` | 도시 설계도: 구역 반지름, 대로, 성벽·운하·해자·농지, 건물 구획 배치 |
| `city/Shapes.java` | 원형 탑, 지붕, 나무, 분수, 수정, 가로등 |
| `city/feature/*.java` | 건물 종류별 코드 (성채, 성문, 마법탑, 학원, 집, 시장, 정원, 분수) |
| `build/CityBuildJob.java` | 청크 단위로 나눠 짓는 작업 (틱당 25ms) |
| `command/MagicCityCommand.java` | `/magiccity` 명령어 |
