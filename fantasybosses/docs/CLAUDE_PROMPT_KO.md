# Claude에게 전달할 요청문

첨부한 FantasyBosses_v0.7.5.1_Claude_handoff.zip은 Minecraft 1.21.1 NeoForge용 공통 챕터 보스 모드의 소스 프로젝트다. v0.7.5 독립 기능은 사용자 인게임 테스트 25/25 정상이고, v0.7.5.1은 오리지널 전용 BGM만 추가한 버전으로 실제 빌드/인게임 오디오 검증이 필요하다. `docs/HANDOFF_KO.md`, `README_KO.md`, 기존 소스와 migration 리소스를 먼저 읽어라.

목표는 v0.8 파티별 독립 전장부터 기존 MagicCity, FantasyRPG, RoyalQoL과 통합하는 것이다. 네 모드는 별도 JAR로 유지한다. 기존 모드팩의 실제 GitHub 브랜치 및 공개 API를 먼저 확인하고, 현재 코드와 설계서의 차이 및 호환성 위험을 기록해라. 임의로 새 챕터 ID/스킬 API를 추정하지 말고 실제 소스에서 확인해라. 기존 라디키온 ID, 모델, 포즈, 보스 이동, 6종 공격, 그로기, 11부위 판정, 흡수 기관/보호막, 알집/유충, 마력 균열, 사망과 소유 개체 정리는 보존해라. BGM은 전투 참가자에게만 재생되도록 전장 컨텍스트와 연결해라.

우선 독립 브랜치에서 기준 버전을 빌드하고 BGM을 포함해 회귀 검증. 이후 고정 절대 좌표 기반 전장을 파티별 원점/차원으로 변환하는 EncounterContext와 서버 참가자 필터를 설계·구현한다. 두 파티가 동시에 싸워도 피해, UI, 기생체, 기관, BGM, 클리어가 섞이지 않아야 한다. 그 다음 기존 RPG 피해 연산 및 진행도 등급을 단일 파이프라인으로 연결하고, 정상 승리 이벤트 및 보상/진행도 갱신을 중복 없이 추가해라. 기존 퀘스트와 밸런스는 임의로 변경하지 마라. 원본 레지온 수정 금지, 월드/저장소 백업, 테스트용 브랜치와 CI 빌드를 사용해라.

첫 작업 결과는 기존 저장소/브랜치 조사, API 근거, v0.8 설계 및 최소 변경 구현/테스트로 구성해라. 실제 빌드 성공, 정적 검사, 게임 실행 검증 여부를 분리하고 아직 미구현·미검증인 부분을 명시해라. v0.9 스토리/보상은 v0.8 격리 검증 뒤 진행한다.
