# royalqol — 마법 왕국 대륙 편의 모드

NeoForge 1.21.1 (21.1.266 이상) **클라이언트 전용** 모드. 서버에는 넣지 않아도 되고, 넣어도 아무것도 하지 않습니다.
같은 저장소의 `magiccity`와 따로 빌드되어 jar도 따로 나옵니다 (`royalqol-<버전>.jar`).

## 받는 방법
- GitHub Actions → 최신 성공한 Build → Artifacts의 `royalqol-jar`
- 직접 빌드: 저장소 루트에서 `./gradlew -p royalqol build` → `royalqol/build/libs/`

필수 의존 모드(클라이언트): JEI, JourneyMap. 이 모드는 두 모드의 API를 호출하지 않고, 모드팩 구성 결정에 따라 함께 설치되도록 선언만 합니다.

## 기능
- **HUD (왼쪽 위):** 좌표와 바라보는 8방위, 게임 날짜·시각, 지금 있는 지역, 가장 가까운 지역(거리·방위), 목적지(거리·화살표). F1·F3 화면에서는 숨김
- **지역 진입 알림:** 지역에 들어가면 화면 아래에 이름 표시
- **목적지 안내:** 도착하면 채팅으로 알리고 안내 종료 (도착 거리 = 지역 반경, 최소 6·최대 32칸)
- **내장 지역 33곳:** 주요 지역 14곳 + 테마 촌락 19곳, 차원 `magiccity:kingdom`, 월드 좌표. 좌표는 `magiccity` 소스의 지역 중심 상수에서 옮겼고, 서리 결투장만 근사값. 반경은 초안
- **내 웨이포인트:** 이 컴퓨터의 `config/royalqol/waypoints.json`에 저장. 차원별로 따로 표시

## 명령어 (클라이언트 명령, 권한 필요 없음)
| 명령 | 내용 |
|---|---|
| `/rq list` | 이 차원의 웨이포인트 전체와 거리 (· 내장, ★ 내가 추가) |
| `/rq near` | 가까운 5곳 |
| `/rq go <이름>` | 목적지 지정. 공백 무시, 앞부분만 써도 됨 |
| `/rq stop` | 목적지 안내 끝내기 |
| `/rq info` | 위치·지역·목적지·HUD 상태·파일 위치 |
| `/rq add [반경] <이름>` | 지금 위치를 웨이포인트로 저장 (반경 기본 16) |
| `/rq remove <이름>` | 내가 추가한 웨이포인트 지우기 (내장 지역은 못 지움) |
| `/rq hud` | HUD 켜기/끄기 |
| `/rq reload` | 파일 다시 읽기 |

## 단축키 (조작 설정의 "왕국 편의 기능"에서 변경)
- **H**: HUD 켜기/끄기
- **G**: 가까운 지역 5곳을 차례로 목적지로 지정

## 코드 구조
- `nav/` — Minecraft 없이 도는 순수 계산: 웨이포인트, 방위·화살표·시각, 지역 판정, JSON. JUnit 11개
- `client/` — 상태·파일, HUD, `/rq` 명령
- `RoyalQol` — 진입점 (`@Mod(dist = CLIENT)`), 단축키·틱 처리
